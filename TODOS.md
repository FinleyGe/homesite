## Blog Cover Workflow

### Local Cover Studio UI

**What:** Build a local visual workspace for generating, revising, previewing, and accepting blog cover images.

**Why:** The CLI workflow may become awkward once multiple cover versions, prompts, and social previews need to be compared visually.

**Context:** The approved blog cover workflow starts with a CLI that stores private drafts and history in `.cover-work`. After the CLI has been used on several real posts, those artifacts can become the data source for a dev-only UI that shows the article brief, current candidate, revision input, accepted metadata, and social preview together.

**Effort:** L
**Priority:** P3
**Depends on:** CLI cover workflow implemented and used on several posts
